# D1.4 — Canal de força da 1ª campanha (C9)
Data: 2026-11-20   Status: aceita

**Contexto:** nos 12 arquivos de `exp_5/`, as colunas `Input 1 [g]` e `Input 2 [N]` têm o mesmo pulso de força. No domínio da frequência, |In1/In2| é plana em 5–300 Hz (variação de 0,4–4 dB) e vale 1,125–1,198 nos 10 arquivos com Input 2 ativo. No aço engaste-livre (2 arquivos), o Input 2 está sem sinal. O pesquisador confirmou que **o martelo estava ligado nas duas entradas** e que o Input 0 é o acelerômetro.

**Opções consideradas**
| Opção | Como funciona |
|---|---|
| A | Força = Input 2 (rotulado N); onde o Input 2 está sem sinal, Input 1 ÷ razão In1/In2 mediana dos outros arquivos |
| B | Força = Input 1, como no legado |
| C | Manter `exp_5/` pendente |
| D | Usar a 1ª campanha só para frequências e ζ (escala irrelevante) |

**Decisão (do pesquisador):** A. O pesquisador confirmou a ligação e autorizou seguir as recomendações (2026-10-31). A restrição de D vale na prática: a escala absoluta tem ±15 % de incerteza e não serve para validar amplitudes.

**Justificativa:** o rótulo N e as velocidades de martelo plausíveis apontam o Input 2 como o canal com a conversão para newtons. Para ζ e frequências os dois canais são equivalentes (mesma forma). A razão mediana, 1,135, é estável (1,125–1,198), o que permite usar o Input 1 nos 2 arquivos do aço engaste-livre.

**Consequências:**
- `data/catalog.yaml` traz `force_channel`, `force_scale_to_N` e `force_note` por arquivo. 2ª campanha: canal 2, fator 1. 1ª campanha: canal 2, fator 1; aço engaste-livre: canal 1, fator 1/1,135 = 0,881.
- A 1ª campanha passa de "pendente" a no máximo "utilizável" (um registro por configuração, escala ±15 %): **10 utilizáveis e 2 descartados**, porque o acelerômetro saturou em acrílico engaste-livre m-ponta e alumínio engaste-livre m-centro.
- Código: `dampid.eda.c9` (tabela de razão e atribuição), aplicado no notebook 06 da Fase 1.
- O legado usava o Input 1 sem correção: as amplitudes de FRF do TCC ficam ~13 % abaixo (força ~13 % maior), além dos erros de C2–C7.
