# D0.1 — Gerenciador de ambiente
Data: 2026-10-31   Status: aceita

Contexto: definir como o ambiente Python é recriado (máquina do pesquisador e sandbox).
Opções consideradas: (A) `uv` + `pyproject.toml` + lockfile; (B) conda/mamba + `environment.yml`.
Decisão (do pesquisador): **A — uv**, conforme recomendação.
Justificativa: rápido, reprodutível, um comando (`uv sync`); conda pode ser acrescentado se FEniCSx for escolhido na D4.2.
Consequências / o que muda no código: `pyproject.toml` com grupos `dev` e `legacy`.
**Limitação registrada:** no sandbox da Fase 0 o PyPI está bloqueado pela política de rede (proxy respondeu 403 para `pypi.org`), então o `uv.lock` **não pôde ser gerado aqui**. A auditoria rodou com os pacotes pré-instalados (versões em `docs/reports/fase0/00_setup.md`). Ação: rodar `uv lock && uv sync` na máquina do pesquisador e versionar o `uv.lock`.
